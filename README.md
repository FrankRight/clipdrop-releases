# ClipDrop downloads

Installers for [ClipDrop](https://clip-drop.xyz), a desktop app for saving videos and music from YouTube, TikTok,
Instagram, Facebook and X. This repository holds the downloads only.

**Get the latest version at [clip-drop.xyz](https://clip-drop.xyz)**, or from [Releases](../../releases/latest):

| File | For |
|---|---|
| `ClipDrop-Setup-<version>.exe` | Windows 10 and 11 (64-bit) |
| `ClipDrop-<version>-macOS-arm64.dmg` | Macs with Apple silicon (M1 and later) |
| `ClipDrop-<version>-macOS-x86_64.dmg` | Intel Macs |
